THE NEXT LIKELY MOVE

Not one perfect memory.
A portfolio of imperfect ones.

The evidence points toward hybrid depth schedules: cheap recurrent or local layers for most tokens, compressed memory for continuity, and occasional learned sparse exact reads when uncertainty or retrieval value justifies the cost.

Most layersGated state / local windowcheap continuity
Some layersCompressed memorylong-range summary
Few layersSparse exact retrievalhigh-value recall
“Long context” is not a number. It is a system spanning position, compute, cache, training data and evaluation.
